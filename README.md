📌 Project Objective

The objective of this project is to analyze Amazon product sales data and create an interactive Power BI dashboard to identify sales trends, product performance, category performance, and customer review patterns.

🛠️ Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Data Cleaning
- Data Transformation
- Data Visualization

📈 Key Insights

- Analyzed $2.18M YTD Sales
- Analyzed $811.09K QTD Sales
- Analyzed 27.75K YTD Products Sold
- Analyzed 19.42M YTD Reviews
- Compared monthly and weekly sales trends
- Analyzed sales performance by product category
- Identified the Top 5 products by YTD Sales
- Identified the Top 5 products by YTD Reviews
- Added interactive filters for product category and quantity

The dashboard provides an interactive view of Amazon product sales performance, including:

- YTD Sales
- QTD Sales
- YTD Products Sold
